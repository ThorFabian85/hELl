# hELl website - GitHub Pages

Upload all files/folders in this ZIP to the root of a GitHub repository.
Then enable GitHub Pages under Settings > Pages > Deploy from a branch > main / root.

The website includes:
- browser-friendly MP3 piano playback plus downloadable original WAV and MIDI
- interactive ONE CONSCIOUSNESS cycle
- interactive HELL -> EL burn-away title
- Believers lyrics
- screenplay download
